Song library

Public-domain carols, arranged with the melody in the right hand and chords in the left. Hymn melodies and chords were taken from published hymnal editions (Musicam Ecclesiae's English Hymns and Ben Kuhn's carol book).

Your songs

Load a MIDI file of any song (higher track or notes above middle C go to the right hand), or type one in.

Write a song

One token per note: E4:1 is E4 for one beat, R:1 is a rest, C4+E4:2 is two notes together. Left hand can use chord names (C, G7, Am, F:2); with no length a chord lasts one bar. key: sets the key signature on the staff (C, G, F, Em, Bb…). A right-hand note with no length reuses the previous length. | marks bars and is checked.

Settings

Saved in this browser.
